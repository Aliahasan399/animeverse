## 📦 Features

| Feature | Description |
|---------|-------------|
| **🏠 Homepage** | Hero section with stats, category showcase, featured products carousel, newsletter |
| **🛍️ Shop** | Full product catalog with sidebar filters — category, search, price range, sort |
| **📄 Product Detail** | Image gallery, series/variant selector, accordion info, related products |
| **🛒 Cart** | Add/remove, quantity controls, order summary, LocalStorage persistence |
| **♥ Wishlist** | Heart toggle on every product, persists across sessions |

<br>

## 🎨 Design

- **Dark anime theme** — deep navy/purple palette with gradient accents
- **Glassmorphism** — frosted glass cards with backdrop blur
- **Smooth animations** — hover effects, scroll transitions, toast notifications
- **Fully responsive** — mobile, tablet, desktop breakpoints

## 🛠️ Tech Stack

```
HTML5       — Semantic markup, SEO meta tags, Open Graph, Schema.org
CSS3        — Custom properties, Grid, Flexbox, Glassmorphism, Keyframes
Vanilla JS  — ES6+, LocalStorage, URL params, Event delegation
GitHub Pages — Free static hosting, automatic deployment on push
```

**Zero dependencies** — no frameworks, no build tools, no npm packages.

## 🔧 Local Development

```bash
# Clone
git clone git@github.com:Aliahasan399/animeverse.git
cd animeverse

# Serve locally (any HTTP server works)
python3 -m http.server 9091

# Open in browser
open http://localhost:9091
```
